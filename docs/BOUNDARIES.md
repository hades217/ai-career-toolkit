# What this toolkit does / 工具包边界

The repository provides original editable templates, bilingual process guidance, a fully fictional application case and a small runnable lexical-retrieval artifact. It is a standalone educational resource, not a live account or product demo of Job Hunter, JobPin AI or any other linked service.

The example job is not a live vacancy; the example candidate has not applied or interviewed. Career history is stipulated fiction. Running the local code demonstrates only the code's retrieval behaviour. It does not validate the fictional employment, produce a resume automatically or demonstrate production AI delivery.

Optional prompts are plain text for an existing chat session. No provider call, key, backend, package installation, telemetry, email or submission is part of this repository. The work sample uses the Python standard library, local synthetic records and terminal output only. It writes no files.

The toolkit does not create PDFs. Any future PDF deliverable must first have a corresponding HTML/CSS source whose print layout has been verified, then be rendered from that same source. Do not claim a Markdown file is a verified PDF export.

Product descriptions are limited to public entry-page purposes. Links are not proof of account access, payment, current vacancies, installer acceptance, AI execution or career outcomes. General reference links are supplementary, not a license to copy their templates or an endorsement from those organisations.
