# Contributing / 贡献指南

Contribute original, reusable career tools: templates, evidence methods, fictional cases and publicly sourced guidance. English and Chinese navigation should stay aligned. Questions and sample answers must remain English unless the owner explicitly requests otherwise.

欢迎贡献原创模板、证据方法、虚构案例和有公开来源的指南。中英文入口保持一致；题目、示例回答与解释保持英文。

- Label every invented identity, employer, role, outcome or scenario as fictional. Do not submit real resumes, private JDs, contact databases, client documents or credentials.
- Keep candidate fact IDs, requirement IDs, complete skills inventory and claim lineage consistent. Distinguish work from personal projects, and plans from completed work.
- Include complete outputs, not only cover cards or claims about what a tool could create. Runnable examples must explain their actual limits.
- No guaranteed job, salary, ATS pass, fake score or unsupported impact metric. Do not copy proprietary question banks, resume content or product source code.
- Product links must be official, categorised by purpose and labelled as maintainer-affiliated where applicable. No paid placement or affiliate links.
- This repository includes no model integration, telemetry, automatic outreach or application submission. Do not add provider calls or ask for keys.
- GitHub Actions is disabled and no workflows are included. Do not enable CI, add workflows or deploy without explicit owner authorisation. Use `[skip ci]` commits; do not bypass branch protections or required checks.

- 虚构人物、雇主、岗位与情境必须明确标识，不提交真实简历、私有 JD、客户资料、联系人数据库或凭据。
- 事实、岗位要求、技能清单和逐句依据保持一致，工作与个人项目、计划与完成结果分开。
- 展示完整结果，不只放标题和封面。可运行例子说明实际能力与限制。
- 不承诺就业、薪资或 ATS 通过，不编造分数或指标，不复制私有题库、简历及产品源代码。
- 产品使用官方入口并按用途分类，维护者关联清楚披露，不做付费排名或返佣。
- 不添加模型调用、遥测、自动外联或投递，不索取 API key。
- 本仓库关闭 GitHub Actions、不配置 workflow。未经明确授权，不启用 CI、添加 workflow 或部署。提交使用 `[skip ci]`，不绕过分支保护和必需检查。
