# Complete example: Alex → Junior AI Engineer

**Entire career scenario is fictional.** Alex, Example Support Services, Example University and Example AI Studio are invented. Contact information uses the reserved example.com domain. The local retrieval artifact is real, small and runnable; it is not a real candidate's commercial work. No application or interview has occurred.
