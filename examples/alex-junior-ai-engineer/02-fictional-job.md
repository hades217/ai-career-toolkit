# Junior AI Engineer — fictional job description

**Teaching fixture, not a real vacancy.** Example AI Studio, Brisbane, Australia. Captured for this case on 2026-10-19. No salary, sponsorship, actual opening or employer affiliation is implied.

## Role

Work with an experienced engineer on small AI application experiments. Explain your decisions, handle uncertainty and help turn prototypes into maintainable components. Personal or university projects are acceptable evidence for this junior position. Production ownership is not an entry requirement.

## Required

- **R01:** Write and explain basic Python, including reading local data and handling unsupported inputs.
- **R02:** Use basic SQL to inspect structured data and explain the scope of the query.
- **R03:** Explain retrieval fundamentals and the difference between a retrieval baseline and an LLM-based application.
- **R04:** Design useful evaluation cases and describe what the evidence does and does not show.
- **R05:** Reproduce problems, communicate clear investigation notes and work with engineering colleagues.
- **R06:** Use version control and document the assumptions and limitations of a project.

## Preferred

- **P01:** Hands-on experience packaging a small application with Docker.
- **P02:** Experience calling a model API or building an agent workflow.
